# 🦍 Gorilla - Offline-First Pro Gym Logger

## 📱 About The Project
An advanced offline-first fitness tracking mobile application designed to visually catalog gym equipment, digitize workout routines, and track progressive overload seamlessly without requiring a constant internet connection.

## ✨ Key Features
* **Offline-First Architecture:** Built with local data persistence via shared_preferences and synchronized with Firebase (Auth, Firestore) when online.
* **Smart 1RM Calculation:** Implemented local algorithms to calculate training volume and Estimated 1-Rep Max (1RM) using the Epley formula.
* **Frictionless UI:** Designed an in-workout interface featuring rapid stepper adjustments, one-tap historical data retrieval, and a custom-built Rest Timer.
* **Progressive Overload Tracking:** Visualizes workout logs to help bodybuilders and fitness enthusiasts track strength gains over time.

## 🛠 Tech Stack
* **Framework:** Flutter (Dart) - MVVM Architecture
* **Database & Cloud:** Firebase (Auth, Firestore), local data caching
* **Algorithms:** Custom 1RM mathematical computation engines
